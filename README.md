# EPUB 工具箱

围绕 EPUB 的处理工具集：一个 Flask 服务 + 一组互不干扰的小工具，用来把电子书拆开看看、洗干净、改改样式，或者换个格式。

启动后是一个环形首页，9 个工具绕成一圈；点进去后变成「左侧导航 + 右侧工具页」。全部处理都在本机完成，不依赖任何外部服务。

## 功能一览

| 工具              | 说明                                                         |
| ----------------- | ------------------------------------------------------------ |
| **EPUB ⇄ TXT**    | 纯文本按章节识别生成带模板样式的 EPUB（可粘贴章节标题示例自动生成正则）；也可把 EPUB 正文按阅读顺序提取成 TXT |
| **注释处理**      | 识别并内联或清理脚注、尾注与跨文件注释链接                   |
| **解包 / 重打包** | EPUB 解包成 ZIP 查看内部结构，或把 ZIP 重新打包成规范 EPUB   |
| **元数据编辑**    | 读取并修改书名、作者、语言、标识符与出版信息，另存为新文件   |
| **文本清洗**      | 按 spine 清洗正文：规范空白、合并断行、清理冗余内联标签、自定义查找替换 |
| **样式排版**      | 安全清理样式表与正文空段，并统一行距、缩进等排版参数         |
| **EPUB格式优化**  | 在现有 CSS 末尾追加紧凑化规则（无 CSS 时自动新建并挂接），或用模板样式替换并注入正文样式类，可选清理空段与 `<br>` |
| **拆分 / 合并**   | 从一本书里抽出选中章节另存为新书，或多本按顺序合并成一本     |
| **简繁转换**      | 简体与繁体互转，可选覆盖正文、目录导航与元数据               |

## 快速开始

需要 Python 3（`启动.bat` 会检查 3.6+；本项目在 3.12 上开发与验证，Docker 镜像也是 3.12）。

```bash
# Linux / macOS / WSL —— 首次会自动建项目内 .venv 并装依赖
./启动.sh

# 停止（按端口定位，默认只停命令行里含 app.py 的进程）
./停止.sh
./停止.sh --status    # 只看状态，不停止
```

Windows 直接双击 `启动.bat`（找解释器 → 装依赖 → 打开浏览器）；或先跑一次 `启动.bat` 装好依赖后，在任意 CMD 里输入 `MyEpubTools`（启动器在已在 PATH 中的 `D:\Books\Tools\MyEpubTools.bat`，后台起服务并打开浏览器）。

服务默认只监听 `127.0.0.1:5000`，浏览器打开 <http://127.0.0.1:5000/>。

容器或云开发环境里需要监听 `0.0.0.0` 才能被端口转发访问（`启动.sh` 会自动识别容器），手动启动时：

```bash
EPUB_TOOLS_HOST=0.0.0.0 EPUB_TOOLS_PORT=5000 python app.py
```

依赖见 `requirements.txt`：Flask、beautifulsoup4、简繁转换引擎 opencc（预编译 wheel，零系统依赖、零传递依赖）。所有功能都在本地运行，不依赖外部服务，也不需要令牌或配置文件。

## 目录结构

```
app.py                  Flask 入口：扫描 modules/ 自动挂载各工具
build_epub.py           TXT → EPUB 的构建逻辑（章节识别、模板样式复用、OPF/NCX 生成）
sample_test.epub        TXT → EPUB 的默认模板；各 CSS 末端已含「正文紧凑化」关键规则

modules/
  registry.py           工具（Blueprint）自动发现与排序
  toolkit.py            通用工具页框架：声明式配置 → 页面 / 统一响应 / 上传与打包
  epub_io.py            EPUB 读写公共层：解包、重打包、成员路径校验、文本解码
  epub_package.py       OPF / NCX 文档级读写：定位 OPF、元数据、目录标题、spine 正文
  epub_text.py          正文清洗与「按文本节点改写」能力
  epub_css.py           样式表扫描、安全清理与排版覆盖
  epub_optimize.py       格式优化公共层：紧凑 CSS 追加 / 无样式自动新建、模板样式替换与类注入
  epub_assemble.py      组装新书（拆分 / 合并用）
  epub_convert.py       简繁转换
  epub_to_txt.py        EPUB 正文提取为纯文本
  其余 *.py              每个工具一个模块，内含 TOOL 元信息

templates/              外层壳（首页 / 侧边导航）、通用工具页壳
static/                 外层壳样式脚本、通用工具页样式脚本
web/                    「EPUB ⇄ TXT」那套独立页面（早期工具，未走通用框架）

启动.sh / 停止.sh         Linux / macOS / WSL 启停
启动.bat                 Windows 启动
```

## 开发约定

- **不改的文件必须逐字节不变**：工具只重写真正改动过的文件，其余原样保留。
- **产物统一 OPF 2.0 + NCX**，`mimetype` 永远是首个条目且不压缩（STORED）。
- **错误一律返回中文 JSON**，前端直接显示，不暴露堆栈。
- **一个工具一个 `modules/*.py`**：模块里声明 `TOOL = {key, title, url_prefix, order}` 即被自动挂载；
  没有 `TOOL` 的模块会被自动跳过，当作公共层使用。
- **改动都配验证**：每轮新增断言脚本，并回归全部历史脚本。

## 已知限制

- 「选择文件夹」按钮依赖 tkinter，在容器或无图形界面的环境里不可用，改用手填输出路径。
- 转换产物默认写在项目内 `outputs/`。
- 简繁转换的「通用繁体」用 OpenCC 的 `s2t`，输出「爲 / 裏」这类旧字形；想要现代「為」请选台湾正体或香港繁体。
